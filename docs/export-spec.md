# Export Specification

Exports should preserve enough context for later review.

Core fields:

- `record_type`
- `generated_at`
- `claim`
- `risk_score`
- `risk_level`
- `components`
- `flags`
- `review_actions`
- `decision_note`
- `inputs`
- `method`

Exports are intended to be stored with source notes, review dates, and any downstream decision records.
