# Catalyst Narrative Risk WordPress Package v1.5.0

Shortcodes:

```text
[catalyst_narrative_risk_demo]
[catalyst_narrative_risk_workspace]
```

The analytical interface supports evidence-ledger inputs, claim decomposition, typed narrative links, wording variants, and advisory map diagnostics. `narrative-risk-method.js` is generated from the canonical v1.5.0 method JSON. `narrative-risk-map.js` implements the browser map contract. The browser and Python engines produce identical canonical records and SHA-256 digests.

The workspace stores cases, immutable revisions, review comments, staged governance workflows, reviewer assignments, decisions, conditions, publication controls, search state, and archive state in the visitor's browser and transfers complete v1.5.0 checksummed case bundles. Institutional deployment should use the SQLite-backed REST workspace API for shared persistence.
