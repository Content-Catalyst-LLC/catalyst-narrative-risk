# Catalyst Narrative Risk WordPress Interface v1.10.0

Shortcodes:

```text
[catalyst_narrative_risk_demo]
[catalyst_narrative_risk_workspace]
[catalyst_narrative_risk_publication_workspace]
[catalyst_narrative_risk_public_brief]
```

The analytical interface demonstrates canonical scoring, evidence ledgers, claim decomposition, narrative maps, and exact browser-method behavior.

The browser-local workspace demonstrates cases, immutable revisions, review comments, staged governance, monitoring snapshots, narrative-change comparisons, watchlists, alerts, timelines, and complete v1.10.0 checksummed case bundles. Browser data remains on the current device. Shared institutional persistence and scheduled monitoring should use the SQLite-backed REST workspace API.

The v1.10.0 publication workspace previews governed briefs and exports JSON, Markdown, and HTML. The public-brief shortcode renders escaped public display content. Institutional PDF/CSV/JSON-LD publication, API scopes, embeds, and platform handoffs use the persistent REST workspace.
