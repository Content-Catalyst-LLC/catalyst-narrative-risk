# Catalyst Narrative Risk v1.3.0

## Persistent Cases and Review Workspaces

This release turns canonical narrative-risk files into durable review cases without weakening the immutability or reproducibility of analytical records.

### Added

- SQLite case repository and schema-version metadata
- Persistent case metadata, tags, status, priority, archive, and restore
- Immutable numbered revisions with canonical record hashes
- Review events linked to cases and optional revisions
- Append-only activity protected by SQLite triggers
- Saved views and validated search filters
- Portable checksummed case bundles
- Bundle verification and transactional import
- Workspace REST API and command-line interface
- `[catalyst_narrative_risk_workspace]` WordPress shortcode
- Browser-local workspace mode for offline demonstration
- v1.2.0 canonical record migration
- Case, revision, review-event, saved-view, and workspace-bundle schemas

### Boundary

v1.3.0 provides persistent workspaces and review history. Multi-user assignment, permissions, approval stages, due dates, and institutional governance policy remain planned for v1.5.0.
