# Catalyst Narrative Risk v1.0.1

## Scoring Parity and Release Integrity

This repair release establishes one reproducible scoring contract across Python, browser JavaScript, CLI exports, the Flask API, and the WordPress demo.

### Repairs

- Corrected JavaScript truthy fallbacks that replaced valid zero weights for `official_or_primary`, `strong`, and `reviewed` values.
- Extracted the browser scoring logic into a reusable, Node-testable engine.
- Added canonical normalization for whitespace, choices, text values, and source counts.
- Added explicit failures for missing claims, malformed source counts, non-object payloads, and unsupported fields.
- Added stable method and schema version fields to generated records.
- Strengthened the JSON Schema and validated API and CLI outputs against it.
- Moved the unrelated portfolio-risk compatibility shim into `narrative_risk/legacy.py`.

### Release integrity

- Six valid parity fixtures, including zero-weight and 39/40 threshold boundaries.
- Six invalid-input fixtures with matching Python and JavaScript error messages.
- Direct Python-to-browser output comparison.
- Python 3.11 and 3.13 CI matrix.
- Node syntax and browser-engine contract tests.
- PHP syntax validation and WordPress asset dependency checks.
- Repository version and required-file contract checks.

### Compatibility

The shortcode remains:

```text
[catalyst_narrative_risk_demo]
```

Existing valid v1.0.0 inputs continue to score with the intended Python weights. Browser records that used zero-weight values may now receive lower, corrected scores.
