# Catalyst Narrative Risk v1.1.0

## Canonical Narrative Risk Contract and Method Engine

v1.1.0 converts the v1.0.1 scoring repair into a durable analytical contract. Records no longer expose a flat collection of fields whose provenance must be inferred. They explicitly separate normalized inputs, calculations, machine interpretation, and human decisions.

### Contract identity

The release introduces stable identifiers for the contract, record, case, method, record schema, and input schema. Each record embeds the full method snapshot and its SHA-256 digest.

### Reproducibility

A record can be rebuilt exactly from its normalized input, original identifiers, generation time, human decision, and embedded method snapshot. The verification report checks full-record equality and the method, input, and payload digests.

### Controlled method

Weights, thresholds, source-count ranges, defaults, controlled vocabularies, component rationale, remediation guidance, flag rules, action rules, and decision notes are versioned data rather than undocumented code constants.

### Migration

The release migrates schema-valid v1.0.1 records while preserving score and risk level. Migration assigns deterministic record and case IDs, records explicit warnings, and leaves the human disposition undecided.

### Release gate

- 33 Python tests
- 6 valid and 10 invalid cross-runtime fixtures
- Exact Python–JavaScript score, record, canonical JSON, and SHA-256 parity
- Schema-valid sample generation and exact reproduction
- v1.0.1 migration and post-migration reproducibility
- JavaScript and PHP syntax validation
