# Catalyst Narrative Risk v1.10.0

## Security, Privacy, Accessibility, and Production Hardening

This release prepares the governed narrative-risk platform for production deployment while preserving the v1.9.0 analytical, evidence, mapping, governance, monitoring, stakeholder, comparative, and publication contracts.

### Added

- Secure Flask defaults, explicit CORS allowlists, request-size limits, HTTPS enforcement options, hardened cookies, and security response headers.
- Tamper-evident security-readiness and aggregate production-readiness reports.
- Versioned privacy and retention policies with case-level retention assessments and legal-hold support.
- Verified SQLite backups, integrity checks, foreign-key checks, manifest hashes, and restore drills.
- WordPress accessibility audits covering labels, controls, focus visibility, reduced motion, landmarks, and headings.
- Performance budgets for health checks, case search, bundle generation, bundle size, and database size.
- Database health diagnostics, production API endpoints, CLI operations, and a readiness shortcode.
- Deterministic migration from v1.9.0.

### Method boundary

Production hardening evaluates explicit configuration and operational evidence. It does not certify a deployment as secure, replace penetration testing, guarantee regulatory compliance, or remove operator responsibility for infrastructure, identity, encryption, incident response, and recovery.
