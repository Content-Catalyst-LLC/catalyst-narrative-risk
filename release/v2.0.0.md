# Catalyst Narrative Risk v2.0.0

## Connected Narrative Risk and Claims Governance Platform

v2.0.0 completes the roadmap by joining the canonical analytical engine, evidence ledger, narrative map, persistent workspaces, human governance, monitoring, stakeholder intelligence, comparative scenarios, publication controls, and production hardening into one connected institutional platform.

### Added

- Ten-module first-party Catalyst registry.
- Tamper-evident platform profiles.
- Persistent idempotent cross-module events.
- Checksummed integration routes.
- Unified case dossiers.
- Exact organization-scoped institutional workspaces.
- Connected REST and CLI operations.
- Connected records in portable case bundles.
- WordPress connected-platform shortcode.
- Deterministic v1.10.0 migration.

### Compatibility

The v1.10.0 analytical weights and all inherited evidence, mapping, governance, monitoring, stakeholder, comparative, publication, privacy, and hardening policies remain unchanged. v2.0.0 is an additive orchestration release.

### Boundary

Connection metadata coordinates governed artifacts. It does not certify truth, create publication approval, infer authorization, combine tenants, or bypass module-specific controls.
