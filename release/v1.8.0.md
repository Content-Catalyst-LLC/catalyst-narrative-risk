# Catalyst Narrative Risk v1.8.0

## Comparative Narratives and Scenario Analysis

This release adds persistent, evidence-linked comparison and scenario capabilities while preserving the v1.7.0 analytical, governance, monitoring, and stakeholder contracts.

### Added

- Persistent comparison sets with explicit baselines, frames, assumptions, and immutable record references.
- Claim-by-claim comparative evidence matrices and coverage-divergence summaries.
- Best-case, base-case, worst-case, counterfactual, adversarial, and custom scenarios.
- Checksummed scenario results that never mutate baseline records.
- Multi-dimensional sensitivity analysis and ranked score drivers.
- Comparative case portfolios and publication-readiness summaries.
- Checksummed Decision Studio handoffs.
- SQLite, REST, CLI, WordPress, and portable-bundle support.
- Deterministic migration from v1.7.0.

### Method boundary

Comparative outputs are advisory. The system does not certify truth, select a preferred narrative or scenario, infer probability, or approve publication automatically.
