# Catalyst Narrative Risk v1.9.0

## Briefing, Publication, API, and Platform Integration

This release converts governed narrative-risk cases into public-safe, portable publication artifacts while preserving the v1.8.0 analytical, governance, monitoring, stakeholder, and comparative contracts.

### Added

- Audience-specific briefing records tied to immutable case revisions.
- Governance-aware public-safety gates, conditions, disclosures, redactions, validity, and reassessment metadata.
- Checksummed JSON, Markdown, HTML, PDF, CSV, and JSON-LD publication artifacts.
- Versioned publication packages with idempotency, lifecycle status, public URLs, and artifact manifests.
- Revocable public embeds.
- Hashed, scoped API keys with expiration and per-minute rate limits.
- OpenAPI 3.1 discovery document and publication REST endpoints.
- Checksummed handoffs for Knowledge Library, Research Librarian, Site Intelligence, Catalyst Data, Catalyst Canvas, Decision Studio, and external systems.
- WordPress publication workspace and governed public-brief shortcode.
- Deterministic migration from v1.8.0.

### Method boundary

Publication readiness is a governance result, not a score result. The system does not publish a public narrative unless an explicit, current human approval permits it. Exports and handoffs preserve conditions and disclosures; they do not certify truth or legal sufficiency.
