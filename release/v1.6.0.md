# Catalyst Narrative Risk v1.6.0

## Narrative Change, Freshness, and Monitoring

This release adds immutable monitoring snapshots, source-freshness evaluation, narrative and evidence drift comparison, watchlists, alerts, reassessment scheduling, a unified case timeline, and a Site Intelligence handoff. The v1.5.0 scoring, evidence, narrative-map, and governance boundaries remain advisory and are not silently changed by monitoring.

## Release gates

- Python unit, API, migration, persistence, monitoring, and bundle tests.
- Exact Python–JavaScript scoring and canonical-record parity.
- Browser valid and invalid fixture matrix.
- JSON Schema validation for all monitoring objects.
- Monitoring CLI workflow and exact bundle round trip.
- v1.0.1 through v1.5.0 migration and reproduction.
- JavaScript and WordPress PHP syntax.
- Clean package and installer upgrade verification.
