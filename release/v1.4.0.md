# Catalyst Narrative Risk v1.4.0

## Claim Decomposition and Narrative Mapping

This release adds a canonical narrative-map layer to the existing claims, evidence, scoring, and persistent-workspace platform.

### Added

- deterministic narrative nodes, links, wording variants, and issue identifiers
- factual, causal, predictive, normative, recommendation, assumption, context, and unknown node types
- typed decomposition, dependency, causal, predictive, support, qualification, contradiction, context, recommendation, and sequence relationships
- entity, geography, time-scope, quantity, and baseline fields
- wording comparison and advisory risk-direction metrics
- structural diagnostics for ambiguity, overbreadth, causality, prediction boundaries, baselines, confidence, orphan nodes, missing claim mappings, and cycles
- narrative-map JSON Schema, method policy, controlled vocabularies, digest, and exact reproduction
- JSON, Markdown, and Mermaid map exports
- REST and WordPress narrative-map interfaces
- v1.3.0 migration

### Compatibility

The weighted scoring algorithm and evidence-ledger derivation policy are unchanged from v1.3.0. Existing workspace data remains compatible. v1.3.0 records migrate without score, risk-level, ledger, or human-decision changes.

### Boundary

Narrative diagnostics are review aids. They do not verify truth, infer motive, establish causality, or approve public use.
